# CodeVault - Encrypted Private Notepad

CodeVault is a dynamic, fully-encrypted, code-entry notepad that provides anonymous users the ability to create distinct private workspaces via unique codes. 

## 🔥 Features
* **Demon Slayer UI Modes**: The entire frontend dynamically transitions!
  * Click **Create Data** to activate **Thor Mode** (Electric Cyan Lightning).
  * Click **Access Data** to activate **Zenitsu Mode** (Thunderclap Gold Lightning).
* **Two-Step Verification**: Note entries can be protected by passwords (PIN).
* **File Uploads**: Supports multiple file uploads inside notes (Max 20MB per file).
* **Note Expiration**: Automatic expiration handling via backend schedules.
* **Revision History**: Supports saving the latest 20 edit differences natively.

## 🛠 Tech Stack
* **Backend**: Python, Flask, SQLAlchemy, bcrypt
* **Database**: PostgreSQL (Production ready), SQLite (Local fallback)
* **Frontend**: Vanilla JS, Vanilla CSS, HTML5
* **Editor**: CodeMirror (Full syntax highlighting)
